# Áudios das aulas narradas — Auditor Fiscal Pro

Arquivos de áudio (`<topicId>.opus`) que o app baixa sob demanda quando o aluno abre uma aula.
Os slides, roteiros e o restante do app ficam em outro repositório.

Para publicar uma aula nova ou regravada: copie o `<topicId>.opus` para a raiz deste repositório,
faça commit na branch `main` e envie. O app detecta versão nova pelo tamanho do arquivo.
